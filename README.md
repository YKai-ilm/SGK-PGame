# SGK-PGame · 三國走圖塔防

手機與桌面共用的網頁遊戲。正式入口為 `index.html`，遊戲主介面為 `主介面流程預覽.html`。

## 建置與發布

需要 Node.js 22 以上，無需安裝執行相依套件。

```
npm test
npm run build
npm run preview
```

Cloudflare Pages：連接 `YKai-ilm/SGK-PGame`，正式分支 `main`，建置命令 `npm test && npm run build`，輸出 `dist`，Node.js 22。

修改、驗證完成後執行 `npm run release -- "本次修改說明"`。這會測試、建置、提交遊戲需要的檔案並推送 main，由 Cloudflare 自動發布；不監看每一次檔案存入，以免發布半成品。僅使用這個專案的 origin，不影響其他遊戲。

建置根據檔案引用收集資源，保留來源藝術在本機。`dist` 不直接提交。首次部署前應確認建置的 publish-inputs.json 與程式無私密資料。

## 存檔與更新

- 進度存在裝置的 localStorage。沒有玩家雲端帳號或自動跨裝置同步。
- 設定 → 完整存檔備份／恢復，匯出 `three-kingdoms-full-save` v1 JSON。包含已儲存的主進度、劇情、背包、隊伍、戰鬥、教學、回顧等；不含GM沙盒與開發用人物編輯草稿。
- checksum 用來發現不完整檔案，不是防作弊簽章。
- 匯入先檢查格式與摘要，再確認覆蓋；保存覆蓋前副本，匯入失敗回復原存檔。其他頁會阻止繼續寫入舊狀態。
- 使用相同 HTTPS 網域保存進度。從 file 網址、不同網域或其他瀏覽器搬家時，先在原環境匯出，再匯入。
- 遊戲更新不清除存檔；新格式須新增版本遷移與測試，不得無聲重置。
- 更新先下載整套核心檔案，全部遊戲視窗回主城閒置才切換。圖片按需快取，未訪問場景不保證離線可用。
- 未來 App 必須支援相同備份格式；不宣稱可直接讀取瀏覽器儲存區。

完整離線、雲端同步與 App 包裝不是此版本功能。
